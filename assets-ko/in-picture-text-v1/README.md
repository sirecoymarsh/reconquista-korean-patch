# 그림 속 일본어 한국어화 (2026-11-27)

대본이 아니라 그림으로 들어 있던 일본어 글자를 한국어로 다시 그린 것. 만드는 도구는
`engine-storymap/tools/floating_text/` (build.py · spec.py · objects.py · objects_spec.py).

`payloads/<묶음>/<이름>` 은 게임 묶음(data.arc, data1.arc)에 그대로 넣는 그림이다. 원래 그림과 같은 꼴
(TC00 은 통째, TC01 은 한국어 바탕 위 차분)이고, 원작과 같은 압축 방식으로 다시 썼다.
4K 그림(hires-jxl)은 고화질 묶음에 들어가므로 여기에는 넣지 않았다. `manifest.json` 에 그림마다 문구·출처·해시가 있다.

| 무엇 | 장수 | 한국어 |
|---|---|---|
| 장면 위에 떠오르는 대사 | 25 | 「이리 와…」 「어서 와… 오빠」 「…네, 맹세합니다」 『자, 치즈…』 「……오라버니!」 『…오빠…』 |
| 시간 건너뛰기 카드 | 16 | 약 N년 전, 약 N주 전, 한 달 후, 몇 시간 전 (숫자는 원래 그림 그대로) |
| 성경 구절 화면 (요한계시록 14:13) | 8 | 본문 번역과 같은 문장 |
| 모미지 손편지 | 10 | 아빠, 언제나 고마워. 앞으로도 계속 같이 있어 줘. 모미지 |
| 엘리베이터 「故障中」 | 14 | 고장중 |
| 수영복 이름표 | 2 | 마호코 |
| 다리 표지판 (낮·밤) | 2 | 자전거·보행자 / 전용 도로 |
| 제목 로고·버스 (1배 그림) | 4 | 4K 그림(코덱스)과 같은 「레콘키스타」 「임해 뉴타운」 |
| 스태프룸 보너스 | 18 | 도타마 만화, 하루 인사말, 라디오 제목, 메모, 말풍선, 효과음, 포스터 |

일부러 두고 온 것: 읽을 수 없을 만큼 작은 글씨(그림책 본문, 묘비, 게시판 종이, 비상구 표지 등)와
스태프룸의 원작 패키지·로고 디자인 과정 그림(kiostaff02, kiostaff03: 원래 일본어 디자인을 보여 주는 그림).
