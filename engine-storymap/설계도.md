## 1. 지금 차트에서 고칠 것

- **게임 화면 밖에 있다.** 4096×2160 창 전체를 덮고, 맑은 고딕과 남색 관리 화면 색이다. 다른 게임 화면(연표·설정·저장)은 모두 4:3 안에 있다.
- **이야기 순서가 안 보인다.** 갈래 묶음을 카탈로그 순서대로 세로줄에 놓아서 도입부 → 최종편 → 공통 → 히로인 순서가 됐다. 잇는 선이 최종편 칸을 비스듬히 가로지른다.
- **장 안 목록이 길다.** 「대사 0001…2013」이 한 줄로 이어진다. 미리보기가 다음 대사 몇 개를 이어 붙여서 같은 글이 두 줄에 겹쳐 나온다(예: 「…하지만 그건 그립기만 한 게 아니라…」가 1291·1292 둘 다에).
- **숨은 화자가 드러난다.** 미리보기에 「＊＊＊（쿠레하）」처럼 괄호 속 이름이 나온다. 게임 대사창이 이 괄호를 숨긴다면 차트가 정체를 먼저 알려 주는 셈이다 → 4.4.
- **이름표가 파일 이름이다.** 「마호코 18_2ero」.

## 2. 게임에서 가져온 문법

이 화면은 게임의 **「연표」(クロニクル) 화면의 형제**로 짓는다. 연표는 원래 「시간 줄 × 인물 세로줄」 표다. 아직 모르는 칸은 회색 「정보 가림」 무늬로 덮는다. 이야기 지도도 「날짜 줄 × 갈래 세로줄」 표라서 짜임이 같다.

| 쓰는 곳 | 원본 자원 (fastdata.arc) | 게임 안 원래 쓰임 |
|---|---|---|
| 지도 틀 전체 | `クロニクル枠_off/on` | 연표 틀: 은빛 가시덩굴, 양 귀 단풍잎, 진홍 돌결 테, 왼쪽 위 진홍·남색 태극 문장, 오른쪽 위 판 넷 |
| 세로줄 머리판 | `名前プレート_*`(진홍 돌결) | 연표 머리줄·대사창 이름판 |
| 신야 쪽 머리판 | 시점 변경 화면의 「미사와 신야」 남색 판 | `視点変更背景_on` |
| 날짜 칸(왼쪽 기둥) | `クロニクル青バー` / `クロニクル灰バー` 돌결 | 연표 왼쪽 「연월」 기둥 |
| 못 본 칸 | `情報隠蔽` | 연표의 가린 칸 |
| 지금 자리 | `momiba*` 단풍잎 | 틀 장식, 타이틀 3 |
| 선택지 | `選択肢台` 진홍 받침 셋(평소·고르는 중·파랑) | 게임 선택지 |
| 장 안 바탕 | `バックログ画面` | 대사 기록 화면(반투명, 멈춘 장면이 비침) |
| 장 안 제목 | 설정·저장 화면의 「⚜ 제목」 진홍 띠 | 모든 체계 화면 머리 |
| 오른쪽 위 단추 | 설정 화면 갈매기꼴 판(진홍·남색) | 「이전 화면으로」「설정 초기화」 |
| 장면 카드 | 저장 칸 카드(`sl_save_n`) 꼴 | 저장·불러오기 |
| 날짜 | 대사창 오른쪽 위 배지 「N일째 · 요일」 | 매 장면 |

**날짜는 게임의 시간 축이다.** 장마다 날짜 넘김 그림 `NNday.rct`(data.arc, 01~19)를 띄운다. 그림은 「18日前 水曜日」…「最終日 日曜日」로, 19일째가 마지막 날이다. 대사창 배지도 「2일째 목」처럼 같은 날을 센다. 장 번호는 대부분 그 장의 날짜와 같다(쿠레하·마호코·시이나). 마사키만 며칠씩 어긋난다(마사키 09 = 10일째).

빛깔은 게임 안의 뜻을 따른다. 빛깔 하나에 뜻 하나다.
- 진홍 = 마키노 시점(대사창 m, 시점 변경 판), 그리고 고른 칸
- 남색 = 신야 시점(대사창 s)
- 파랑 받침 = 예전에 고른 선택지. 설정 「선택한 선택지 → 색상 변경」이 쓰는 색으로 **추정**한다. `menu.mjo`의 `select_color`로 확인할 것.
- 주황(단풍잎) = 지금 자리. 이 뜻에만 쓴다.
- 토요일 파랑 · 일요일 빨강 = 날짜 넘김 그림의 요일 빛깔

글꼴은 게임 것을 쓴다. 제목·판·장 이름은 `font\ReconquistaKRSerif.otf`, 대사·작은 글은 `font\ReconquistaKR.otf`이고 대사창과 같다. 두 글꼴 모두 ✓ ◆ 「」 ＊ 가 있다. ▸ ◂ ↵ ⚜ ✝ 는 없다. 화살표 모양은 판 모양(갈매기꼴)으로, ⚜는 띠 그림으로 해결한다.

## 3. 화면

좌표는 모두 게임 논리 800×600이다. 실제로는 게임 화면 크기(전체 화면 2880×2160, 창 1600×1200)에 맞춰 늘린다.

### 3.1 ① 이야기 지도 · 본편 (`map_main.png`)

- 틀: 연표 틀. 원래 「연표」 자리(225,44 중앙)에 **「이야기 지도」**를 쓴다.
- 오른쪽 위 판 넷(연표의 도움말·새 항목 찾기·추가 이야기 찾기·닫기 자리):
  - 보라 육각: **최종편으로**. 최종편 쪽에서는 **본편으로**. CG 화면에서 회상 화면으로 넘어가는 판과 같은 쓰임이다.
  - 진홍 위: **대사 찾기**
  - 금빛 아래: **지금 자리로**
  - 작은 진홍: **닫기**
  - 도움말은 F1. 아래 안내 줄에 적는다.
- 태극 문장 글자: 위 「갈래」, 아래 「날짜」(연표는 「이름/연월」).
- 머리판(y 74~111): 세로줄 넷(x 94·260·427·594·760). 쿠레하·마사키는 진홍 판, 마호코·시이나는 남색 판이다.
- 도입 띠(y 114~140): 도입부 1·2·3을 왼쪽에서 오른쪽으로 놓는다. 칸 안에 「1일째 수」를 쓴다. 이 줄은 날짜 기둥이 태극 문장에 가려서 날짜를 칸 안에 둔다.
- 날짜 줄(y 140~): 4일째~19일째, 그다음 「그 뒤」(후일담).
  - 한 단 높이는 21이다. 4일째와 5일째는 두 단이다(공통 갈래가 걸쳐 있다).
  - 마키노 공통은 두 세로줄에 걸쳐 4일째 두 단 + 5일째 윗단을 차지한다.
  - 신야 공통은 4일째 윗단, 마호코 04·시이나 04는 그 아랫단이다.
- 같은 날에 장이 여럿이면 칸을 가로로 나눈다: 마사키 10·11, 마호코 12·13, 18·18-2·18-3, 시이나 19·19-2.
- 장이 없는 날(마사키 7·9·12일째, 마호코 13일째)은 빈칸으로 둔다. 갈래 가운데로 가는 실선 하나만 비친다.
- 날짜 기둥: 남색 돌결 칸에 「N일째」와 요일. 「그 뒤」는 회색 돌결이다.
- 아래 안내 줄(y 542~562): 왼쪽에 고른 칸 정보 「쿠레하 05 · 5일째 (일) · 장면 10 · 대사 183줄 · 선택지 없음」, 오른쪽에 「F1 도움말 · Enter 열기 · Esc 닫기」.
- 확대·끌기는 없다. 본편 74장이 이 한 화면에, 최종편 29장이 ②에 다 들어간다.

### 3.2 ② 이야기 지도 · 최종편 (`map_final.png`)

- 같은 틀에 세로줄 둘: **현재**(x 94~470)와 **과거**(x 486~760).
- 현재는 본편과 **같은 날짜 줄**에 놓는다. 현재 01 = 2일째는 도입 띠 자리에, 02 = 4일째, … 16 = 19일째, 결말 후일담은 「그 뒤」다. 현재 장도 `NNday` 그림을 띄우므로 날짜가 확실하다. 탭을 바꿔도 같은 날이 같은 높이에 있다.
- 과거 장에는 날짜 그림이 없다. 그래서 날짜 줄과 일부러 어긋나게 12칸으로 고르게 나눈다. 위에 「날짜 없이 이어지는 이야기」라고 적는다. 날짜 줄에 맞추면 「과거 05가 5일째」처럼 읽히기 때문이다.

### 3.3 ③ 장 안 (`chapter.png`)

지도에서 칸을 누르거나 Enter를 치면 연다. Esc를 누르거나 오른쪽 클릭을 하면 지도로 돌아간다.

- 바탕: 대사 기록 화면 판(반투명)을 쓴다. 멈춘 게임 장면이 어둡게 비친다. 시안에서는 판 아래에 검정 73%를 한 겹 더 깔았다. 판 왼쪽 아래 [RECONQUISTA] 물림 글자는 목록과 겹치므로 이 화면에서는 뺀다.
- 머리:

  - 가운데 연주황 줄 「2일째 (목) · 장면 66 · 대사 2,013줄 · 선택지 4 · 시점 전환 1」(설정 화면 「게임 환경을 설정합니다」 자리와 빛깔)

### 3.5 조작

- 지도: 방향키로 칸을 옮기고, Enter·두 번 누르기로 장을 연다. Tab은 본편↔최종편, G는 지금 자리로, F1은 도움말, Esc·F11은 닫기(원래 대사로)다.
- 장 안: ↑↓ 줄, ←→ 장면, PgUp/PgDn·Home/End, Enter·두 번 누르기 = 이동, Esc·오른쪽 클릭 = 지도로, F11 = 닫기. 휠은 목록을 굴린다.
- 도움말(F1): 게임 `ボタン説明`(검정 판에 흰 글자 목록) 꼴로 위 조작을 적는다.
- 소리: 게임 UI 소리(`on.ogg` 올림, `push.ogg` 누름, `cancel.ogg` 취소 — 쓰임은 파일 이름으로 짐작)를 게임 효과음 크기로 낸다 → 결정 ⑨

## 4. 자료 (flowchart.bin에 더할 것)

### 4.1 장의 날짜
- 장 안에서 첫 대사보다 앞에 `NNday` 그림이 있으면 그날이다. 없으면 앞 장의 마지막 날을 잇는다.
- 칸은 **장 안의 마지막 날**에 놓는다. 전날 밤에 시작해 다음 날로 넘어가는 장이 많다(쿠레하 08 = 7→8일째). 마지막 날 기준이면 장 번호와 날짜가 맞는다.
- 후일담(`_ep`·`_epi`·`last_ep`)은 「그 뒤」에 놓는다.
- 시안 계산: `tools/chapter_days.py` → `ref/chapter_days.json`. 날짜 그림이 없어 앞 장을 이은 곳은 모두 날짜 배지 변수로 한 번 확인할 것: 마호코 13(=12일째로 둠), 마사키 06·11, 쿠레하 05, 마호코·시이나 04.

### 4.2 장면
- 장면은 **검정(또는 흰·빨강) 화면을 지난 뒤 새 그림이 깔리는 곳**에서 나눈다. 바로 바뀌는 그림과 이벤트 CG는 장면을 나누지 않는다.
- 이렇게 나누면 도입부 1 = 24, 2 = 66, 3 = 56, 마키노 공통 24, 신야 공통 15, 쿠레하 05 = 10장면이다(`tools/scenes.py`).
- 장면 카드 그림은 그 장면 안 마지막 `bg_*` 배경만 쓴다. `ev*`(이벤트 CG)·`netu*`·세피아는 **쓰지 않는다**(성인·미성년 장면이 섞여 있다). 배경이 없으면 검정 카드로 둔다.
- 작은 그림은 미리 구운 묶음으로 둔다. 실행 중에 8MB HD 그림을 열지 않는다.

### 4.3 한 줄 = 한 대사
- 대사 노드는 화자와 본문을 따로 가진다. 본문은 그 페이지 글만 넣는다(다음 대사를 이어 붙이지 않는다).
- 지문의 줄바꿈 `n`은 한 칸 띄우기로 바꾼다.

### 4.4 화자 표시
- 게임 대사창 이름 칸이 실제로 띄우는 꼴을 그대로 쓴다. `console.mjo`의 이름 처리를 따른다.
- 「＊＊＊（暮葉）」 같은 괄호가 게임에서 숨는다면 차트도 「＊＊＊」로 쓴다 → 결정 ④

### 4.5 이름표
- `18_2ero` → `18-2`, `18_3` → `18-3`, `19_2` → `19-2`, `_ep`/`_epi` → 후일담
- 도입부 1~3, 마키노 공통·신야 공통, 현재 01~16, 과거 01~12, 결말 후일담

### 4.6 읽음 (결정 ③)
- 게임 읽음 기록 `savedata\majiro_readmark.mss`에서 읽은 페이지를 센다. 장·장면은 「안의 대사를 다 읽음」일 때 ✓다.
- 검수 이동 뒤 읽은 것은 검수 저장 폴더 쪽에 쌓여 원래 기록에 안 남는다. 그래서 「검수한 곳」을 남기려면 차트가 따로 기록해야 한다. 이것도 결정 ③에 들어간다.

## 5. 구현 메모 (코덱스)

- 그리기는 지금처럼 WS_CHILD + GDI다. 다만 **게임 4:3 화면 안**에만 그린다. 바깥 띠는 게임처럼 검정이다. 눌림 판정은 800×600 논리 좌표로 바꿔서 한다(게임 단추와 같은 방식).
- 그림: 연표 틀·판·띠·받침·돌결·단풍잎을 **글자 없는 HD 판**으로 준비한다.
  - 시안은 v16 HD 틀의 글자 자리에 1배 clean 판을 늘려 붙여서 판 글자 자리가 조금 흐리고, 금빛 판에 옛 글자 흔적이 비친다.
  - WIC로 PNG를 읽고 AlphaBlend로 붙인다.
  - 틀·머리판·날짜 기둥은 화면 크기가 바뀔 때 한 번만 구워 둔다. 고른 칸·지금 표시만 그때그때 그린다.
- 글꼴: 게임 `font\` 두 글꼴을 AddFontResourceEx(FR_PRIVATE)로 쓴다. 게임이 이미 올렸으면 그 이름을 쓴다.
- 찾기 칸: 바탕 그림 위에 테 없는 EDIT를 둔다(WS_EX_CLIENTEDGE 빼고, WM_CTLCOLOREDIT로 검정 바탕).
- 이동(FCPrepare/FCJump)·저장 격리·입력 막기·닫기 흐름은 그대로 둔다. 화면이 부르는 대상만 노드 id로 맞춘다.

## 6. 결정할 것 (답이 없으면 기본)

1. **이름**: 「이야기 지도」(기본, 다른 작품과 같음) / 「플로 차트」
2. **날짜 표기**: 「N일째 · 요일」(기본, 대사창 배지와 같음) / 「N일 전」(날짜 넘김 그림과 같음)
3. **읽음 ✓**: 게임 읽음 기록으로 표시(기본) / 안 함. 검수 이동 뒤 읽은 곳까지 남길지도 정한다(기본: 남김, 차트 기록 파일 따로)
4. **숨은 화자**: 게임처럼 「＊＊＊」(기본) / 검수용으로 괄호 속 이름까지
5. **못 본 장 가리기**: 끔(기본, 검수용이라 다 보임) / 켬(읽은 만큼만, 나머지 정보 가림 무늬). 켜면 설정의 「검수용 모든 콘텐츠 개방」(Ctrl+F10)이 켜졌을 때 다 보이게 묶는다.
6. **확대·끌기**: 뺌(기본, 한 화면) / 남김
7. **장면 카드 그림**: 배경만(기본) / 그림 없음
8. **대사 찾기 범위**: 지도에서는 전체, 장 안에서는 그 장(기본) / 지금처럼 장 안만
9. **UI 소리**: 게임 소리(기본) / 없음
