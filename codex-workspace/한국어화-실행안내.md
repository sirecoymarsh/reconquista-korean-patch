# 레콘키스타 한국어판 v13 · 설정 화면과 콘텐츠 개방 버튼


v13에서 설정 화면에 남아 있던 일본어 고정 문구 19개를 일반·선택·누름 상태 57곳에 반영했습니다. 글자 아래 배경은 사용자 허용에 따라 원본풍으로 부분 복원했습니다. 버튼·슬라이더 좌표와 기능은 유지했습니다.

설정 화면 상단의 **모든 콘텐츠 개방 · 현재 꺼짐**을 누르면 검수용 개방이 켜지고, **개방 취소 · 현재 켜짐**을 다시 누르면 해제됩니다. 기존 Ctrl+F10도 사용할 수 있습니다. 실제 클리어 기록은 덮어쓰지 않습니다.

이전 버전은 **Start-Korean-v12.cmd**로 실행할 수 있습니다. 저장 파일은 v12에서 별도 복사했으며 버전 사이에 자동 동기화하지 않습니다. 전체 화면의 사용자 확인은 아직 남아 있고, 다른 미완료 UI 화면은 이번 설정 수정에 포함되지 않습니다.


v12에서는 확대 화면의 WM_MOUSEMOVE 좌표를 원래 게임의 800×600 좌표로 변환합니다. 창 모드와 전체 화면에서 마우스 이동 및 버튼 눌림/해제 신호 검증 9개를 통과했습니다. 실제 화면에서 메뉴를 선택하는 최종 확인은 아직 하지 않았습니다.

타이틀 로고의 작은 세로획을 없애고, 큰 십자가 기둥을 오른쪽으로 옮겨 아래 두 획과 연결했습니다. 첫 레의 뾰족한 장식은 복원했습니다. 타이틀 9개 상태의 일반/HD 이미지에 적용했으며 버튼 좌표는 유지했습니다. 오프닝 영상의 로고 교체는 별도 세션에서 진행합니다.

이전 v11은 Start-Korean-v11.cmd로 실행합니다. 저장 파일과 검수 개방 설정은 v11에서 독립 복사했으며 자동 동기화하지 않습니다.


검수용 전체 개방: 창 모드에서 상단 ‘파일/설정 → 검수용 모든 콘텐츠 개방’을 체크합니다. 전체 화면에서도 Ctrl+F10으로 켜거나 끌 수 있습니다. 처음에는 꺼져 있습니다. 같은 항목을 다시 누르면 개방을 취소합니다.

CG 열람·회상 7개·음악·추가 메뉴·클리어 후 선택지를 임시로 개방합니다. 변경 뒤에는 타이틀로 돌아가거나 추가 메뉴에 다시 들어가세요. 진행 중인 장면을 자동으로 재시작하지 않습니다.

실제 달성·CG 해금 테이블은 유지하고 검수 중의 해금 판정만 바꿉니다. 검수 중 얻은 해당 달성·CG 기록도 원래 테이블에 쓰지 않습니다. 일반 저장 슬롯과 설정은 평소처럼 저장됩니다. 옵션 상태는 이 실행본의 review-unlock.enabled 파일에만 저장됩니다. 읽음 기록 전체를 채우거나 본문 진행 위치를 변경하는 기능은 아닙니다.

숨김 실행 검증에서 개방·취소, 메뉴 이벤트, Ctrl+F10 및 반복 입력, VM 반환값, 원래 달성·CG 테이블 보존을 확인했습니다. 실제 화면의 갤러리 탐색과 회상 재생은 사용자가 검수합니다.

옵션 추가 전 v10 HD는 Start-Korean-v10.cmd로 실행합니다. v10과 v9는 그대로 보존했고 v11 저장 파일은 독립 복사했습니다. 버전 간 저장 데이터는 자동 동기화되지 않습니다.

`Start-Korean-4K.cmd` 또는 `Start-Korean.cmd`로 실행합니다. 최초 메뉴 초기화가 끝나면 모니터 해상도의 전체 화면으로 시작합니다. F4는 전체 화면, Alt+Enter는 큰 창입니다. Windows 디스플레이 해상도를 변경하지 않습니다.

원본의 4:3 비율을 유지합니다. 3840×2160에서는 게임 영역 2880×2160과 좌우480픽셀 여백, 4096×2160에서는 좌우608픽셀 여백입니다. 내부 고해상도 그림은3200×2400이며, 창 모드의 기본 게임 영역은1600×1200입니다. 버튼 판정은 원래800×600 좌표로 역변환합니다.

메인 메뉴9상태·45문구를88픽셀 글꼴로 다시 그렸습니다. 기존 승인된 한국어 문구와 로고 원본을 재사용했습니다. CG·배경1758장과 메뉴 전환 배경4장을 로컬 High Fidelity4×로 확대했습니다. 비교한4모델 중 원래 선의 부드러움·얼굴 형태·채색 보존이 가장 나았습니다. AI 확대는 원본에 없던 세부가 정확히 복원됐음을 뜻하지 않습니다.

작업은 미리 끝낸 PNG를 읽는 방식입니다. 게임 실행 중 AI 추론을 하지 않습니다. 고해상도 그림 캐시는768MiB, 할당 상한은1400MiB입니다. 이식하지 않은 일부 효과·동영상·서 있는 인물의 애니메이션과 작은 UI는 기존 해상도를 사용합니다. 대사 글꼴은v9의 큰 글꼴을 유지합니다. 실제 장시간 플레이의 버벅임 개선을 확정한 버전은 아닙니다.

검증: 전체 자산의 생성 시 크기·PNG 무결성·SHA256, 메뉴 영역45개, PE 코드 보존, 숨김 게임에서 고해상도 복사13종과 출력/좌표 변환을 확인했습니다. 실제 화면의 클릭·대사 잘림·전환 효과와 장시간 플레이는 사용자 확인이 남아 있습니다.

기존 버전은 `Start-Korean-v9.cmd`로 실행합니다. v9 파일을 수정하지 않았고 저장 데이터는 v10에 독립 복사했습니다. 이후 두 버전의 저장 내용은 자동 동기화되지 않습니다. 문제 발생 시v9로 바로 돌아갈 수 있습니다.

실행기는 주요 패치 파일 해시 및 고해상도 자산의 개수/크기를 확인합니다. 고해상도 파일 전체 SHA256 재검사는 필요할 때 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Korean-4K.ps1 -PrepareOnly -VerifyAssets`로 실행할 수 있습니다.
