## UI 번역 기준

공통 지침의 UI 기본어휘를 사용한다. 화면 역할·소비자가 확인된 표시값만 번역하고 리소스 파일명·명령·speaker_token·해시·레지스트리 키는 보존한다. 설정 설명은 간결한 서술형, 확인 질문은 존댓말, 조작 버튼은 명사/동작형으로 맞춘다. 같은 기능과 의미의 반복 원문은 같은 번역을 사용한다. 공간 차이로 약칭이 필요하면 안정 ID별 이유를 남긴다.

인명은 공통 지침의 마키노 게이고, 모미지(紅葉/もみじ 구별 메타데이터 유지), 쿠레하, 요시모리 마사키 등을 이어 쓴다. 새 인명과 크레딧 이름은 실제 표기/음성의 근거를 확인하기 전 추측 확정하지 않고 terminology-proposals에 기록한다. 브랜드와 로고는 원래 식별성을 보존하며 일반 메뉴 문구와 구분한다.

## OP·ED 가사·영상 방침

원본 음성과 음악은 보존한다. 한국어 가창·더빙은 만들지 않는다. 가사 전체와 반복 구조를 확인해 Codex 내부 모델이 직접 한국어 자막을 쓴다. OCR/STT는 원문 복원·타이밍의 참고만 허용하며 불명확한 음절은 미확정으로 표시한다. 곡명·직책은 번역하고 기여자 이름·브랜드·원래 크레딧 정보는 삭제하지 않는다. 번역은 의미 단위/호흡으로 나눠 실제 재생 타이밍에 맞춘다. 길이, 해상도, 프레임 수/속도, 오디오 트랙과 동기, 자막 안전영역, 게임 디코더 호환성을 각각 검증한다.

## 실행 배치와 검증 게이트

1. 지침 저장 → 기존 추출/복원 검증 재사용 → 원본 소비자 기반 UI 목록 확정.
2. 문자열 UI를 화면별 안정 ID로 번역·문맥 검토. 원문/대상/소비자/보호 토큰/프로비넌스를 기록.
3. 이미지 UI 상태별 원본 확인, clean plate, 한국어 조판, 원본 크기·채널·보호 픽셀 검증.
4. 해시로 고정한 원본에서 후보 빌드. 전체 아카이브와 함께 변경 엔트리 페이로드/해시/의미 변경표를 출력. 변경 집합과 허용 집합을 정확히 대조.
5. runtime-ui 한 회차에서 타이틀/설정/저장·불러오기/지난 대사/확인창/추가 화면과 모든 버튼 상태를 가능한 한 묶어 검증. 증거에 PID, EXE 경로·해시, 창 제목, client bounds, 시각, 스크린샷 해시·조작을 기록. 본문 창과 구분하지 못하면 입력하지 않는다.
6. UI의 미번역·미검증 상태가 해소된 뒤 OP·ED 각 변형을 번역·빌드·재생 검증.
7. 최종 변경표·엔트리 페이로드·폰트 제안·복구 기준·검증/미검증 목록을 제공. 배포 포장 시 windows-release-integrity와 release-checklist를 적용.

상태는 source_verified → authored → context_reviewed → static_pass → runtime_pass로 분리한다. 정적 계산이나 접촉시트는 runtime_pass를 대신하지 않는다. 이전에 통과한 무변경 아카이브/MJO 복원은 reports/extraction.json을 근거로 재사용하며 새 어댑터와 변경된 범위만 검사한다. 독립 리뷰는 읽기 전용 오류 탐지에 한해 수행하고 번역·구현은 이 모델이 맡는다.

각 완료 배치마다 progress.json과 정확한 안정 ID 범위를 기록하고 포함 사용량 및 공유 중지 신호를 확인한다. 미완료를 완료로 표시하거나 UI 검증 전 OP·ED로 넘어가지 않는다.

## 백그라운드 검증 방식 변경 (2026-10-22)

사용자 요청: 조작을 빼앗지 않고 헤드리스/백그라운드로 검증한다. 일반 UI 검증은 전용 비표시 Windows 데스크톱과 runtime-ui-bg에서 수행한다. CreateProcessW의 lpDesktop을 지정하며 SwitchDesktop, 전역 SendInput, 실제 커서 이동을 사용하지 않는다. 주 데스크톱이나 본문 실행본을 활성화하는 방식으로 자동 복귀하지 않는다.

전체 화면 전환, 물리 키 입력 타이밍, 영상/음성 동기에는 아직 검증 근거가 없다. 전체 화면 전환으로 사용자 화면을 방해하지 말고 별도 미검증 항목으로 유지한다. 이번 모드 실험은 정상 종료했으며 다음 배치 때 전용 시험본만 다시 시작한다. 원본 대용량 아카이브·동영상은 읽기 전용 하드 링크이므로 절대 수정하지 않는다.
