message_box.mjo::000639의 ロード와 ::000650의 セーブ는 표시 문구가 아니라 확인창 효과음용 부분 문자열 판별 키이다. 표시 문구 변경과 원자적으로 '불러'/'저장'을 함께 적용하는 제안이다. 모든 원본 입력 발생처를 조사한 뒤 적용하고, 불러오기/빠른 불러오기/저장/일반 질문 각각에서 효과음을 검증한다. 기존 일본어 입력이 여전히 가능하면 두 언어를 모두 인식하도록 좁게 확장해야 한다.
