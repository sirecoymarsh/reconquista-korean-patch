# 레콘키스타 인게임 플로 차트 (v18)

Start-Korean.cmd로 게임을 실행한 뒤 F11을 누릅니다. 차트는 현재 게임 화면 안에서 열리며, 장면을 선택해도 게임 프로세스를 다시 실행하지 않습니다.

- 왼쪽 장 카드 → 오른쪽 대사·선택지·분기 → 아래 이동 버튼. 오른쪽 항목을 두 번 클릭하거나 Enter를 눌러도 이동합니다.
- 검색은 선택한 장 안에 적용됩니다. ←/→로 장, ↑/↓·Page Up/Down·Home/End로 항목을 고릅니다.
- 차트에서 일반 마우스 휠로 포인터 중심 확대·축소, 드래그로 이동, F로 화면 맞춤. 오른쪽 목록에서는 휠로 스크롤합니다.
- Esc 또는 F11은 차트를 닫고 원래 대사로 돌아갑니다. 차트를 열어 둔 동안 게임 진행과 게임 쪽 입력은 멈춥니다.

본편 103개 장, 대사 시작점 43,886개, 선택지 40곳, 조건별 분기 대상 91개, 시점 3곳을 수록했습니다. 91개는 플레이어 선택지만을 뜻하지 않습니다. 앞부분을 빠르게 처리해 선택한 지점에 도달하므로 준비 시간이 필요하며, 과거 플레이의 모든 변수 조합을 재현하지는 않습니다.

첫 장면 이동 전에 v17 savedata를 savedata-review-프로세스ID-시간 폴더로 복사하고 이후 저장을 해당 폴더로 보냅니다. 검수 이동한 프로세스는 종료할 때까지 검수 저장을 사용합니다. 일반 진행으로 돌아가려면 게임을 종료하고 다시 실행합니다.

기존 저장 이어하기는 Start-Korean-v16.cmd를 사용합니다. v17은 스크립트 명령 위치가 바뀌어 구버전 수동 슬롯의 호환성을 보장하지 않으며 자동 가져오지 않습니다. 기존 v16·원본·저장 자료는 그대로 있습니다. v17에는 시스템·읽음 정보·글꼴 캐시만 독립 복사했습니다.

대표 3개 루트와 분기 이동, 동일 PID/게임 창 유지, 차트 열기·닫기, 마우스 입력 복귀, 휠 확대, 검색 후 마우스 선택, 정상 종료 뒤 원래 저장 파일 보존을 확인했습니다. 마호코 이름이 최종 HD 출력에서 한국어로 나오는 것도 확인했습니다. 전체 43,886개 지점 재생과 구버전 수동 슬롯 로드는 검증하지 않았습니다. 검증은 무음 전용 데스크톱에서 수행했으며 일반 배포본의 음원은 유지했습니다.

v18은 설정에서 기본/4K CG 전환을 지원하며 전체화면 출력 캐시를 적용했습니다. 자세한 내용은 CG-화질-및-전체화면-안내.md를 참고합니다. v17 저장 파일은 v18에 독립 복사했고, 기존 v17은 Start-Korean-v17.cmd로 실행할 수 있습니다.
