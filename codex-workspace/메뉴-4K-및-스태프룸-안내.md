# 레콘키스타 v19 메뉴 4K와 스태프룸

Start-Korean.cmd로 실행한 뒤 설정(F9)의 「CG·메뉴: 4K / 기본」 버튼을 누르면 CG와 메뉴가 함께 즉시 바뀝니다. 선택은 다음 실행에도 유지됩니다. 콘텐츠 개방/취소와 F11 플로 차트는 그대로 이용할 수 있습니다.

설정, 저장·불러오기, 갤러리·회상, 음악실, 대사창 버튼, 시점 선택, 연표·달력, 스태프룸 등 메뉴 이미지 163개와 대응 마스크를 4배 해상도로 정리했습니다. 한글은 4배 크기로 다시 조판하거나 기존 고해상도 조판을 재사용했고, 스태프룸 제작진 18명의 이름을 한글로 반영했습니다. 원본 배경 무늬는 로컬 리샘플링과 승인된 부분 복원을 사용했습니다.

원본 800×600의 좌표와 화면 비율을 유지한 3200×2400 렌더링입니다. 4K 모니터에서는 원래 4:3 비율에 맞춰 표시합니다. 즉시 전환용 두 화질을 보관하므로 기본 모드가 메모리 절약 모드는 아닙니다.

설정 재진입 때 캐시 이미지에 남은 오래된 투명도 마스크를 조기에 읽던 문제를 수정했습니다. 실제 엔진을 무음 전용 데스크톱에서 실행해 화질 왕복, 대표 메뉴 표시·입력, 원래 저장 자료 보존을 확인했습니다. 사용자의 전경 화면과 장시간 플레이 전수 검증을 뜻하지는 않습니다.

v18과 기존 저장 자료는 보존했습니다. v19에는 현재 v18 저장 파일을 독립 복사했습니다. 이전 버전은 Start-Korean-v18.cmd로 실행할 수 있습니다. 이번 변경은 메뉴와 스태프룸 인명이며, 본문 잔여 범위와 기존 날짜 전환 이미지 22장의 일본어 캡션은 기존 진행 기록을 따릅니다.
