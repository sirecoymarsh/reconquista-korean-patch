# 레콘퀴스타 한국어 번역 기준

대사와 서술은 일본어 원문에서 직접 번역한다. 한국어 문장만 읽어도 자연스럽게 이어져야 하며, 제어 코드와 음성/배경/분기/원본 인물 식별자는 보존한다. 일본어의 문장 경계 때문에 한국어 서술어를 어색하게 끊지 않는다.

서막 쿠레하: 차분하고 단정적인 반말. 정체불명 상대: 담담한 존댓말; 원문의 후속 정중체에 맞춤. 모미지→아빠: 밝은 어린이 반말, 과도한 아기 말투 추가 금지. 마키노→모미지: 다정한 반말. 서술: 과거/현재 혼용의 원문 시점을 유지하며 담백하게.

원본 speaker_token은 내부 식별자이므로 번역하지 않는다. 표시 직전의 이름 복사본에만 매핑을 적용한다. 숨은 (暮葉) 등은 노출하지 않는다. 대상 문자열마다 원본 안정 ID 및 해시를 보관하며 번역 상태는 실제 적용된 범위만 완료로 기록한다.
추가 확정: 紅葉는 아내/모미지의 어머니로, 딸 もみじ와 발음이 같다. 모두 모미지로 표기하고 문맥상 필요한 곳에서 아내/엄마로 지칭한다. 暮葉(쿠레하)와 혼동하지 않는다. 모미지→마사키: 마사키 언니. 마사키→마키노: 마키노 아저씨. 마키노→장인: 아버님, 존댓말. 장인→마키노: 케이고 군/자네, 온화한 하게체. 甲斐性なし는 이 장면에서 무능력자. 원문 노래 『とおりゃんせ』의 이름은 『도랸세』, 반복 가사는 동일 번역을 쓴다.

확인된 특수 표시 소비자: yazlib의 2f93f26a는 강조어 본문, 3198fd01은 먼저 읽는 법·다음 본문을 전달하는 루비 출력이다. 첫 스크립트의 해당 네 호출/일곱 리터럴을 별도 안정 ID로 번역한다. 한국어에서 읽는 법이 중복되는 루비는 ASCII 공백 한 칸으로 지정하고 본문은 유지한다. 제어 명령은 보존하며 공백 루비의 실제 표시·다음 글자 위치는 런타임 확인이 필요하다.
