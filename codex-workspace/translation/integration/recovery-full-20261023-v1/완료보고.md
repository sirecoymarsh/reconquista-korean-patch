# 레콘키스타 한국어 본문 통합본

본문 46,913구간 / 일반 필드 73,314개 / 인라인 625개를 적용했습니다.
이번 보류 재검토에서 일반 대사·서술 20구간을 복구했고, 기술 보류 5구간을 해결했습니다.

- 일반 실행 파일: `レコンキスタ.exe` (원본 실행 파일, 변경 없음)
- 제품 디스크: `P:\GAME\Reqonquist Novel H\Reconquista.iso`를 읽기 전용으로 연결해야 합니다.
- 루트의 `Start-Korean-Recovery.ps1`은 디스크와 패치 해시를 확인한 뒤 이 사본을 실행합니다.
- 게임 본체와 새 글꼴은 P:의 별도 실행 사본에 설치되어 있습니다. 기존 사본과 원본은 보존했습니다.

글꼴 1,398글자의 CP932 표시·Unicode 표시 일치 검사와 새 교체 필드의 컴파일 결과 검사를 통과했습니다.
화면 제어 도구 초기화 실패로 이 빌드의 실제 게임 화면 검증은 아직 완료하지 못했습니다. 수동 루비의 위치, 화자 이름, 장문 줄바꿈은 실제 화면에서 추가 확인이 필요합니다.

본문 보류 37구간과 의미 미확정 1구간은 원문을 유지했습니다. UI·오프닝·엔딩은 별도 세션의 작업이며 이 본문 통합본의 완료 범위에 포함되지 않습니다.
선택지 문자열이 바뀌면서 이전 선택지 읽음 표시 일부가 이어지지 않을 수 있습니다. 전체 루트·세이브 호환성 검증은 미완료입니다.
